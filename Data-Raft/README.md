# generar_dataset_mejorado.py

Script for generating the 15,000 Q&A pairs used to train ChatAcredita PRO, a domain-specific assistant for Colombian university accreditation (CNA framework). It implements the **RAFT** strategy (Retrieval-Augmented Fine-Tuning): each question is generated by giving the LLM the correct document chunk plus 2 distractors from other PDFs, forcing grounded answers that cannot be produced from general knowledge alone.

---

## Installation

```bash
pip install groq pymupdf pymupdf4llm tiktoken tqdm
```

Set your Groq API key:

```bash
export GROQ_API_KEY="your_api_key_here"
```

---

## Quick Start

```bash
# Generate from scratch using CNA corpus PDFs
python generar_dataset_mejorado.py --pdfs ./corpus --output dataset_mejorado.json

# Merge with an existing dataset and generate new pairs
python generar_dataset_mejorado.py \
  --pdfs ./corpus \
  --original dataset_acreditacion.json \
  --output dataset_mejorado.json

# Clean and deduplicate an existing dataset only (no API calls)
python generar_dataset_mejorado.py \
  --original dataset_acreditacion.json \
  --output dataset_clean.json \
  --solo-limpia
```

---

## Arguments

| Argument | Default | Description |
|----------|---------|-------------|
| `--pdfs` | `./corpus` | Folder containing source PDF files |
| `--original` | *(empty)* | Existing dataset to clean and merge |
| `--output` | `dataset_mejorado.json` | Output file name |
| `--model` | `llama-3.3-70b-versatile` | Groq model to use |
| `--max-chunks` | `50` | Max chunks per PDF (`-1` = all) |
| `--workers` | `3` | Parallel threads for API calls |
| `--api-key` | `$GROQ_API_KEY` | Groq API key (alternative to env var) |
| `--solo-limpia` | — | Only deduplicate existing dataset; skip generation |

## Pipeline

```
PDFs ──► chunks (600 chars, overlap 100) ──► quality filter
                                                   │
                                     RAFT prompt: correct chunk
                                     + 2 distractors from other PDFs
                                                   │
                                         Groq API (llama-3.3-70b)
                                                   │
                                     validation: len ≥ 20/40 chars,
                                     ends with "?", no hallucination
                                     phrases detected
                                                   │
              existing dataset ──► cleaning ───────►│
                                                   ▼
                        exact dedup (MD5) + fuzzy dedup (Jaccard bigrams, θ=0.85)
                                                   │
                                       dataset_mejorado.json
```

### Question Templates (15 total, 5 categories)

| Category | Weight | Examples |
|----------|--------|---------|
| Factual | 25 % | "What does the text establish regarding {topic}?" |
| Procedural | 20 % | "What process is described for {topic}?" |
| Causal | 20 % | "Why is {topic} important in the accreditation context?" |
| Comparative | 20 % | "What differences are mentioned in the text regarding {topic}?" |
| Multi-factor | 15 % | "How does {topic} contribute to the program's self-assessment?" |

### Quality Filters (`es_par_valido`)

- Question ≥ 20 characters and ends with `?`
- Answer ≥ 40 characters
- No hallucination phrases: `"as an AI"`, `"I don't have access"`, `"the fragment does not mention"`, etc.

### Deduplication

1. **Exact**: MD5 hash of the lowercased question text
2. **Fuzzy**: Jaccard similarity over bigrams, threshold 0.85, sliding window of 2,000 pairs

## Output Format

Each pair in `dataset_mejorado.json` follows the ChatML format:

```json
{
  "id": "decreto1330_a3f4b2c1d8e9f012",
  "source": "decreto1330.pdf",
  "messages": [
    {"role": "user",      "content": "What does Decree 1330 establish regarding...?"},
    {"role": "assistant", "content": "Decree 1330 of 2019 establishes that..."}
  ]
}
```

## Results in ChatAcredita PRO

Using the CNA corpus from EISC/Univalle (10 GB, ~40 PDFs):

| Metric | Value |
|--------|-------|
| Pairs generated | 15,000 |
| Pairs accepted by RAG-VSD | 9,847 (65.6 %) |
| Estimated cost (Groq) | ~USD 0 – USD 19 |
| Approximate runtime (3 workers) | ~5 hours |

> **Note**: This script uses `llama-3.3-70b-versatile` via Groq. The ChatAcredita PRO paper documents GPT-4o Mini as the original generator; both produce functionally equivalent datasets for the CNA corpus.
